# Promo ROI Optimizer

**Zion Promo ROI Optimizer** — incremental promo lift measurement and promo-calendar recommendations so you stop funding discounts that would have happened anyway.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/promo-roi-optimizer/

## ✨ Features
- **Incremental lift measurement** — causal lift per promo, channel and segment (not vanity ROAS).
- **Cannibalization detection** — spots promos that pull demand forward or erode full-price sales.
- **Promo calendar optimizer** — recommends when to run, deepen or kill each promotion.
- **Budget reallocation** — shifts spend toward promos with proven incremental margin.
- **Scenario simulator** — forecast revenue/margin of next quarter's calendar before committing.
